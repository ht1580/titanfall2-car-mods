# CAR 神话皮 1.1.0 独立动画核对

- 第一人称编译模型包含 100 个序列，其中新增 `mythic_motion`、`mythic_eye_motion`、`mythic_wing_motion`。
- 三个序列均为循环、增量、自动播放；普通射击、换弹、切枪和移动序列没有再叠加引用它们。
- 枪身顶点固定在 `def_c_base`；眼睛顶点绑定 `def_eye_body`；左右翅膀分别绑定 `def_wing_upper_arm_l_1` 与 `def_wing_upper_arm_r_1`。
- 第三人称稳定骨架只有 22 根骨骼，因此只保留核心旋转，不强行加入眼睛和翅膀层。
- 枪口附件继续采用向枪身后移 0.65 模型单位的设置。
- 与 1.0.10 对比，45 个共有非模型资源哈希全部一致，变更集中在模型、版本说明与核对记录。
- 已完成编译、二进制结构核对和 Blender 预览；未启动游戏验证。
